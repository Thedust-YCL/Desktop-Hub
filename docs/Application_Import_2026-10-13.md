# 应用自动发现与桌面位置提示

日期：2026-10-13（Asia/Shanghai）。

“我的应用 → 添加应用”默认合并当前用户的实际个人桌面目录与公共桌面目录，筛选 EXE / LNK。此机的 `C:\Users\Public\Desktop\微信.lnk` 已通过原生列表检查，用户无需进入公共目录手动寻找。

可选择其他文件夹，勾选“包含子文件夹”后重新扫描；按名称、路径或来源搜索，勾选后每次最多添加 100 项。列表异步加载本地图标，失败时显示默认图标。保留“手动选文件”与现有应用的“更换文件”。重复目标、启动参数和有效工作目录的应用，以及损坏、失效或不支持的入口，显示逐项跳过原因；有效项一次保存。

每次进入添加流程先说明个人桌面与公共桌面的区别。“不再提醒”默认不勾选；未勾选则下次进入再次显示，勾选并继续后单独持久保存 `suppressDesktopLocationNotice`。重启保留，不随外观设置的延迟保存被覆盖。取消提示不改变偏好。

扫描不登记文件资源库来源、不建立监测、不启动程序。原生桥接确认通过当前扫描令牌与候选 ID 完成，不接受界面传入的路径；新扫描使旧令牌失效，添加前重新验证文件。保留已有启动策略。递归跳过目录联接、符号链接及未下载文件，限制深度、数量与扫描时间；不可读取的来源显示说明，不阻止另一桌面扫描。
