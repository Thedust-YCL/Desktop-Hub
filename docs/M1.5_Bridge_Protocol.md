# Desktop Hub M1.5 — 应用库通信扩展（协议 v1）

日期：2026-10-10（Asia/Shanghai）。本扩展沿用 M1 的受限 WebView2 请求/响应通道及本地 origin。M1 文档为历史基线；当前启动入口以本文和实现为准。

## 接口

| 请求 | payload | 权限 | 返回 |
| --- | --- | --- | --- |
| `apps.add` | `{}` | Workspace | 原生 EXE/LNK 选择器；`{cancelled,app,settings,appIcons}` |
| `apps.replaceTarget` | `{appId}` | Workspace | 原生选择器更换 target/entryKind/icon，保留 ID、名称、参数、工作目录及布局；取消不写配置 |
| `apps.update` | `{appId,name,arguments,workingDirectory,pinnedToMini,pinnedToDock}` | Workspace | 更新单条记录及固定状态；`{settings}` |
| `apps.remove` | `{appId}` | Workspace | 移除记录和应用固定引用；`{settings}`。不删除原软件或 LNK |
| `apps.reorder` | `{appIds:[id,...]}` | Workspace | 完整 Workspace 应用顺序，原子保存 |
| `launcher.setPins` | `{surface,pins:[{itemType,itemId,enabled},...]}` | Workspace | 完整 Mini/Dock 顺序；应用和场景独立类型引用 |
| `apps.launch` | `{appId}` | 全部 | `LaunchResult {success,processId,code,message}` |

`app.getState` 和 `state.changed` 包含 `settings.appEntries`、`settings.launcherPins`、`appIcons`（ID 到本地 PNG data URL 的映射）。`settings.save` 增加 `dockIconSize`：`compact / normal / large`。其他窗口和设置接口沿用 M1。

Dock 允许只保存 `dockIconSize` 的补丁，其他设置仍由 Workspace 管理。

前端不能通过设置补丁写入程序路径、应用列表、固定列表、图标文件引用或窗口坐标。启动请求只接受登记 ID，不接受命令、任意路径、参数或提权 verb。所有请求及嵌套固定入口拒绝未知/重复字段，沿用来源检查、版本检查和请求并发限制。

普通请求继续限制为 16,384 个字符；仅 `apps.update`、`apps.reorder` 和 `launcher.setPins` 的完整配置/排序允许最多 1,048,576 个字符。配置文件限制为 16 MiB UTF-8 序列化数据，此为安全容量边界，不设置固定的应用条目数量上限。

## 本地数据及启动边界

配置 schemaVersion=2，继续使用 `%LOCALAPPDATA%/DesktopHub/settings.json` 的同目录临时文件、flush 与原子替换。旧 `launchTarget` 仅用于迁移，当前应用列表不以它为启动来源。应用存储与界面固定引用共享稳定 ID；Workspace `displayOrder` 与两套 `LauncherPin` 顺序独立。Mini 最多四个可见固定入口，应用库没有单条限制。

LNK 使用 Windows COM 的 `IPersistFile.Load` 与 `IShellLinkW.GetPath` 读取元数据，不调用 `Resolve` 搜索目标，也不写回快捷方式。启动时重新读取实际目标，校验本地普通 EXE 与 PE 文件头。添加时导入参数和工作目录；之后使用应用库保存的参数（空参数覆盖 LNK 默认参数），工作目录为空时回退到最新解析 EXE 所在目录，目标则读取最新 LNK。更换目标不重新导入参数/目录，用户可在编辑器中调整。程序、命令及脚本执行宿主黑名单沿用 M1；UNC、网络盘、协议、脚本、嵌套 LNK、Windows Installer 特殊入口、Store/MSIX 和要求提权的快捷方式不作为已支持项。

使用 `ProcessStartInfo`、`UseShellExecute=false`，参数传入目标进程，不经系统命令解释器，不申请管理员权限。`success=true` 表示 Windows 返回了创建进程的结果；不保证软件完成初始化，也不保证其随后不崩溃。路径失效、无权访问、无效 PE、工作目录失效及 Windows 拒绝启动返回实际错误。

真实图标由原生层提取并按 PNG 内容哈希缓存到配置目录下 `icons/`；提取或读取失败统一回退。缓存只保存图像，不改软件文件。界面仅接收缓存内容，不使用外部图标网站。

场景固定引用当前仍对应原型演示实体。M1.5 不增加完整场景执行器、依赖等待、脚本或文件索引。后续场景可使用 `AppEntry.Id` 与核心查询/启动接口复用程序配置；当前不存在以独立应用自动创建场景的操作。

## 实现依据

快捷方式读取依照微软的 [IShellLinkW.GetPath 文档](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ishelllinkw-getpath)；特殊标志依照 [SHELL_LINK_DATA_FLAGS](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/ne-shlobj_core-shell_link_data_flags)。本地图标提取参考 [SHGetFileInfoW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shgetfileinfow) 和 [ExtractIconExW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-extracticonexw)，提取得到的 HICON 在编码后释放。
