# Desktop Hub 交互改进 · 2026-10-10

本轮按用户反馈修改正式 Windows 宿主及 `desktop/` 界面，继续沿用 Quiet Desktop 的配色与本地业务逻辑。

- 设置中的主题、位置、尺寸、显示模式、图标密度和悬停延迟均显示为分段按钮。高亮在选项间滑动，支持方向键、Home/End 和系统减少动画偏好；保存刷新期间仍保留动画进度。设置导航、正文和操作字体同步放大。
- Mini 不透明度改为 0–100% 滑块，拖动显示即时百分比，结束拖动后保存；后端允许精确保存 0 和 1。关闭透明效果时仍沿用原有不透明显示规则。
- Workspace 默认居中，最大初始尺寸 960×640 DIP，并限制在工作区的 80% 内。旧版本近全屏默认尺寸进行一次缩小迁移；其他已有尺寸保留。边缘与四角可请求 Windows 原生缩放，最小尺寸 640×480 DIP；用户调整后的尺寸继续保存。首页功能按钮、应用图标与外围留白更紧凑。
- 页头增加上一步/下一步，支持鼠标后退/前进侧键、Windows 浏览器导航命令和 Alt+左右方向键。返回时恢复资源库搜索、标签、扩展名、滚动位置与临时文件夹；离开未保存的场景草稿继续要求明确选择。
- 我的应用增加收藏星标。添加应用不再自动加入 Dock；收藏和取消收藏同步管理 Dock 的应用入口，应用本身仍保留。已有 Dock 应用入口视为已收藏，场景入口不受影响。
- 失效资源面包屑为“启动台 / 文件资源库 / 失效资源”，父级可点击，页面提供“返回文件资源库”。
- 资源库先显示标签分类，选定分类后展开具体标签；所选标签独立展示，支持跨分类组合筛选。时期标签不再全部平铺在筛选区，展开区限制高度并可滚动。
- 分类可新建并持久化；新建标签必须选择分类。旧标签按既有主题、时期、自定义类型归入对应分类，保留稳定 ID、收藏和文件关联。
- 文件夹排在前面，文件按扩展名和名称排序，同扩展名连排；扩展名筛选在分页前执行，并与搜索、标签、收藏及失效状态组合。另有文件夹与无扩展名筛选。
