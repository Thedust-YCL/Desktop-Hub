# M2.2 资源库与交互修复

日期：2026-10-10（北京时间）。沿用现有 Windows / WPF / WebView2 工作台及深浅主题，修复文件浏览、导入和刷新时的使用体验。

## 交互与布局

- 名称、标签、状态、操作使用共享网格列。文件名 15px、路径 12px、标签及状态 13–14px，避免状态跟随文件名宽度漂移。
- 操作固定为收藏、详情、打开；点击区域高度 40px，打开位于最右侧。标签建议收进详情入口，列表不再为每个建议额外占一整行。
- 文件夹使用覆盖整行的独立浏览按钮，支持鼠标及 Enter / Space；收藏、标签、详情、打开仍各自处理点击。临时浏览的子文件夹采用相同方式。
- 1000px 和最低 640px 窗口均保留三项操作，没有横向滚动。窄窗口按名称、标签、状态、操作重新排布。

## 首次导入与时间标签

确认来源时提示“是否按修改时间自动添加所有标签”，可明确允许或暂不添加；取消扫描不记录选择。允许后按修改年月生成时期标签（例如“2026年10月”），覆盖全部索引而非当前 60 项分页，保留手动标签和收藏。相同月份复用标签与关联，不重复添加。

选择写入资源元数据的可空 `autoTagByModificationTime` 字段。既有资源文件可直接加载；尚未做过选择的库在下次导入时显示提示。选择允许后，新入库资源沿用此行为。已添加时间标签作为入库时的时间分类保留，不随之后每次文件编辑更换。

## 动效与滚动

刷新不再重复播放整个 Workspace / Mini / Dock 从透明到不透明的动画。弹窗和提示使用 6px 的轻微位移，遮罩平滑变化；在已经打开的弹窗中切换内容不重播遮罩和进入动画。减少动画设置仍有效。

公共渲染器按当前页面保存滚动位置、输入选区、操作焦点和带 ID 的展开区域，并在桌面适配器完成更新时同步恢复。不同模块正常从页面起点进入；同页的收藏、标签、主题或后台刷新不把工作台拉回顶部。
