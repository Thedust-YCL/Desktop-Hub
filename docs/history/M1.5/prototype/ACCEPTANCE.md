## 浏览器验收环境与结果

实际访问 `http://127.0.0.1:4174`，使用 Codex 内置 Chromium 浏览器。未读取浏览器版本号。静态服务只绑定本机；直接 `file:` 打开方式未通过本轮受限内置浏览器验收，用户可在普通 Edge / Chrome 中双击打开。

- 窗口尺寸：1440×900、1024×768、640×780；首页六入口和六模块页面未出现横向溢出。资源表格在窄窗口内单独横向滚动。
- 深浅主题：首页均已截图；另外保存 Mini、Dock、深色资源库和浅色编辑器截图，见 `screenshots/`。
- 运行时错误：浏览器控制台 error / warn 均为空。
- 实际点击：首页六入口、返回、三状态；引导扫描勾选及确认、位置选择、引导重置；场景新增/保存/删除、等待窗口默认 10 秒、循环依赖拦截、创作/游戏/休闲模拟启动；文件三视图、建议确认与多标签归集、临时浏览、修复保留收藏、清理预览取消、搜索、标签创建/编辑/删除；主题、Mini 顶部名称模式、目录添加/递归/移除、排除程序添加/移除、动效与透明开关、模拟自启/托盘、隐藏恢复策略必选/恢复、快捷键冲突与重置。
- 实际键盘与鼠标：Alt+D、Alt+W、Ctrl+K、Esc；边缘停留可展开，全屏游戏及排除程序保护阻止展开；首次必要确认不能被 Esc 跳过。
- 自动化补充：依赖失败与独立继续、排序、2–4 固定约束、脚本 once 默认、建议拒绝/编辑及确认前关系保护、仅失效索引清理、保护切换时取消旧计时、Space 快捷键、HTML 转义、存储恢复等。

## 主要交互清单

下列清单保留为后续人工复验步骤。`[x]` 表示本轮在实际浏览器中完成，未勾选项表示已由代码/自动化覆盖或属于进一步人工复验；不能把未勾选项解释为尚未实现。每步始终只修改模拟状态。

### 首次使用与公共导航

- [x] 新状态首次打开出现欢迎页；必要步骤不能通过 `Esc` 或遮罩误点跳过。
- [x] 欢迎 → 扫描预览；勾选 / 取消勾选即时更新数量，确认前索引仍为空。
- [x] 点击确认后才写入所选模拟索引；显示模拟索引确认反馈。
- [ ] Mini 左 / 右 / 顶部选择可点；进入 Launchpad 后所选位置生效。
- [ ] “创建第一个场景”进入新建编辑器；保存后返回场景中心并可固定 Mini。
- [x] 首页六入口均可进入；二级页可返回 Launchpad，标题与返回路径清晰。
- [x] 顶部 Mini / Dock / Workspace 演示按钮均可切换到对应状态。
- [x] 在模拟 Edge 前台打开 Workspace，`Esc` 关闭并显示返回模拟窗口反馈。

### Mini、Dock 与场景运行

- [ ] Mini 仅展示所选固定场景；提示名称清晰；默认三个示例为创作、游戏、休闲。
- [x] Mini 场景点击进入模拟运行；从 Mini 可打开 Dock / Workspace。
- [x] 非 Workspace 状态下，屏幕指定边缘默认约 500 ms 悬停展开 Dock。
- [ ] 短暂经过边缘不展开；鼠标移入展开 Dock 内不闪烁或立即关闭。
- [x] 创作反馈按加速器、Clash、ChatGPT、Edge、DSH 展示；成功、已运行跳过、失败及依赖跳过均明确标为模拟。
- [x] 游戏与休闲场景可分别模拟启动；每次运行反馈与对应场景匹配。
- [x] 场景运行结束 Dock 保持展开；关闭入口 / `Esc` 可主动收起。
- [x] `Alt+D`、`Alt+W` 分别控制 Dock 与 Workspace；顶部按钮可替代被浏览器占用的组合。

### 场景中心与编辑器

- [ ] 新建、重命名、删除场景均作用于本地模拟数据；取消编辑不改动已保存场景。
- [ ] 场景可拖拽或用箭头排序；Mini 固定项与场景中心 / 设置中的选择一致。
- [ ] 固定数量限制为 2–4；超过上限或低于已有正常下限时给出明确提示。
- [ ] 新建动作；程序、网页、文件、文件夹、脚本类型均可配置模拟目标。
- [ ] 左侧选中动作与右侧参数相对应；修改名称、目标后界面同步。
- [x] 顺序、并行、固定延迟、等待进程、等待窗口可切换；等待类默认超时 10 秒。
- [ ] 依赖、延时、超时、重复策略、高级参数可配置并保存；动作顺序调整有效。
- [ ] 通过已有文件选择演示脚本目标；不提供内建脚本编辑器，不运行脚本。
- [x] 配置循环依赖后不能保存 / 启动，并能回到参数区修改。
- [x] 保存后返回场景中心，启动采用保存后的动作；程序跳过、依赖失败、独立动作继续等反馈符合演示规则。
