# 首次启动引导 · 2026-10-11

正式 Windows 版本新增六步使用引导：欢迎、导入、使用、桌面图标、开机自启、完成。沿用现有界面、深浅主题和对话框键盘焦点管理，窗口较小时内容区域可滚动，底部操作保持可用。

## 行为

- 未完成引导时，手动启动打开 Workspace 并展示引导。登录启动 `--startup` 保持安静常驻，用户随后打开 Workspace 时可进行引导。
- 导入使用现有原生目录选择器、扫描预览、递归预览与时间标签选项。确认导入前不建立索引；取消或确认后回到同一步。取消后可重新选择，导入也可以直接跳过。
- 使用步骤介绍应用添加、启动与收藏，文件搜索、标签、文件夹浏览，以及创建场景和固定入口。可直接添加真实应用；展示当前已保存的快捷键。
- 桌面图标步骤读取 Windows 状态。首次隐藏必须主动选择完整退出后的处理策略；显示与隐藏都调用现有系统接口。状态未知时可以重新读取。保留 Windows 自身的恢复路径说明。
- 开机自启步骤展示真实状态，提供开启、关闭和移动后按当前位置修复；只管理当前用户的自有启动项。
- 浏览步骤和点击“下一步”不修改系统设置。完成或跳过仅通过原生设置接口保存 `onboardingCompleted=true`。写入失败会留在引导中显示原因，可重试。
- “设置 → 系统与恢复 → 使用帮助 → 重新引导”随时可重看。重看不重置完成记录、应用、来源、标签、收藏或偏好；只有用户主动执行的操作会改变相应内容。
- 未结束引导时退出程序，下次手动启动从欢迎页重新开始。已有成功导入或保存的内容保留。

`onboardingCompleted` 是 settings schema 4 中的可选布尔字段，缺省为 false。旧配置保持正常加载，在下次手动启动出现一次引导。Mini、Dock 不安装引导界面；已有诊断验收模式保持独立。
