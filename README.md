# Desktop Hub · 让桌面成为你的工作主场

**应用随手打开，场景一键就绪，文件集中发现。**

Desktop Hub 是一款面向 Windows 的本地桌面工作台。把常用应用、工作场景和分散的文件入口收拢到一起，从轻巧的 Mini，到快速展开的 Dock，再到完整的 Workspace，让桌面跟上你的工作节奏。

**三种界面 · 场景组合启动 · 本地文件索引 · 统一搜索 · 托盘常驻**

[快速开始](#快速开始) · [特色功能](#把重复操作交给工作台) · [源码运行](#从源码运行)

## 一个工作台，三种打开方式

| 界面 | 适合什么时候使用 |
| --- | --- |
| **Mini · 轻巧入口** | 留一个便于访问的桌面入口，随时进入工作台。 |
| **Dock · 常用直达** | 展开固定入口，快速打开常用应用。 |
| **Workspace · 完整工作空间** | 集中管理应用、编排场景、查找文件和整理项目。 |

应用收藏与 Mini / Dock 固定入口分别管理：收藏你想保留的工具，把最常用的入口放在手边。

## 把重复操作交给工作台

### 一键进入场景，让工作准备连起来

把应用、网页、文件、文件夹和脚本组合成一个场景，按需设置依赖与等待。一次执行，串起原本需要逐个打开的工作入口；执行结果可查看，失败项可单独重试。

例如，为“开始开发”组合编辑器、项目文件夹和参考网页，为“资料阅读”组合阅读工具、文档和笔记入口。场景还支持保存与恢复窗口布局，让常用工作环境更容易重新就位。

### 文件留在原处，资源集中发现

文件资源库通过**本地索引**归集桌面或自选目录中的文件入口，原始文件保留在原来的位置。

- **先预览，再导入**：确认内容后才建立索引；目录默认只索引直接子项，可按来源开启递归。
- **按自己的方式整理**：标签、收藏、筛选与批量整理，配合目录监测追踪资源变化。
- **查找之后继续工作**：支持临时文件夹浏览、图片 / PDF 预览，以及失效引用重新关联。
- **整理更安心**：清理索引或移除来源只修改索引元数据，不删除原始文件；重新关联可保留标签与收藏。

### 常用应用，从散落入口到随手可达

扫描桌面或自选目录中的应用入口，批量添加、分组、搜索并独立启动。结合统一搜索、最近使用和项目集合，让应用与资料围绕手头的工作组织起来。

### 随时唤出，按你的习惯常驻

托盘、单实例、独立全局快捷键与轻量常驻模式，让工作台随时可用。关闭 Workspace 后继续常驻，再次启动会唤出已有实例。

支持深色 / 浅色 / 跟随系统主题，可调整窗口尺寸、不透明度、紧凑布局与减少动画偏好；还可按需开启开机自启、整体显示或隐藏桌面图标。

## 快速开始

当前版本：**0.3.1 · Windows x64**。技术栈：**.NET 8 / WPF / WebView2**。

安装版包含 .NET，缺少 WebView2 时由安装程序检测并下载安装。普通启动直接显示 Workspace，开机自启保持后台常驻。安装版支持在“设置 → 系统与恢复 → 软件更新”中检查、下载并确认重启更新。构建和发布步骤见 [发布说明](RELEASING.md)。

本机已有便携版时，双击根目录的 `打开 Desktop Hub.lnk`，或运行：

```text
artifacts/desktop-hub-0.3.1/Desktop Hub.exe
```

上述新版便携包已包含 .NET，但需要已有 WebView2 Runtime。正式安装版会检测并安装缺少的 WebView2。普通使用无需 Node.js 或本地服务器。快捷方式和发布产物仅保存在本机，未纳入 Git；从仓库获取源码后，请按下一节构建运行。

首次手动启动会展示使用引导，也可在“设置 → 系统与恢复 → 使用帮助”中重新打开。

1. **添加常用工具**：从 Mini 进入 Workspace，在“我的应用”添加应用，按需收藏或固定入口。
2. **创建第一个场景**：在“场景中心”组合日常需要的应用与资料，执行后查看结果。
3. **接入文件资源**：在“文件资源库”选择个人桌面或自定义目录，预览并确认导入。公共桌面需要主动授权。

| 操作 | 默认方式 |
| --- | --- |
| 展开 / 收起 Dock | `Ctrl+Alt+D` |
| 唤出 Workspace | `Ctrl+Alt+W` |
| 收起 Workspace | `Esc` 或右上角关闭按钮 |
| 完整退出 | 托盘菜单“完整退出” |

Dock 与 Workspace 的快捷键可分别修改。开机自启和桌面图标隐藏默认关闭；普通启动与登录启动均不自动执行场景。

## 从源码运行

在仓库根目录使用 **PowerShell 7（pwsh）**。首次下载并校验固定版本的开发依赖，缓存位于 `.tools/`：

```powershell
pwsh -File .\scripts\bootstrap.ps1
```

依赖就绪后，离线构建并启动：

```powershell
pwsh -File .\scripts\build.ps1 -Offline
pwsh -File .\scripts\run.ps1 -Offline
```

`build.ps1` 默认运行后端与前端自动化测试，前端测试需要 Node.js。`run.ps1` 在缺少构建产物时会先构建。

## 你的数据，保存在本机

数据目录：`%LOCALAPPDATA%\DesktopHub\`。

| 数据 | 保存内容 |
| --- | --- |
| `settings.json` | 应用、场景、固定入口、外观及系统集成设置 |
| `resources.json` | 资源来源、索引、标签和文件收藏 |
| 同目录中的独立元数据文件 | 最近使用与项目集合 |

首次隐藏桌面图标时需要选择退出策略。软件未运行时，可通过 **桌面空白处右键 → 查看 → 显示桌面图标** 恢复显示。
